# Real-Time Fraud Detection System

## Software Engineer Internship Project

**Author:** Nikhil Mali

---

## Project Overview

The Real-Time Fraud Detection System is a cloud-native microservices architecture designed to identify fraudulent financial transactions in real time.

The platform combines rule-based fraud detection, machine learning models, graph-based relationship analysis, event-driven processing, and risk assessment services to provide scalable and reliable fraud prevention capabilities.

This project was developed as part of a Software Engineer Internship Program and focuses on architecture design, governance, security, deployment planning, operational readiness, and compliance requirements.

---

## Project Objectives

* Detect fraudulent transactions in real time
* Support high-volume transaction processing
* Enable scalable microservices deployment
* Ensure security, compliance, and auditability
* Provide monitoring and operational visibility
* Support future AI and analytics enhancements

---

## Architecture Overview

The system follows a microservices-based architecture consisting of:

* API Gateway
* Transaction Ingestion Service
* Fraud Rules Service
* Machine Learning Service
* Graph Analysis Service
* Risk Assessment Service
* Case Management Service
* Notification Service
* Audit Service
