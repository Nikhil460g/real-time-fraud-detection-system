# Service Catalog

## Overview

This document provides a catalog of all services in the Real-Time Fraud Detection System.

| Service | Purpose |
|----------|---------|
| API Gateway | Entry point for all requests |
| Transaction Ingestion Service | Receives transaction data |
| Fraud Rules Service | Executes fraud detection rules |
| Machine Learning Service | ML-based fraud scoring |
| Graph Analysis Service | Relationship analysis |
| Risk Assessment Service | Final risk calculation |
| Case Management Service | Fraud investigation workflow |
| Notification Service | Alert generation |
| Audit Service | Audit logging |

## Benefits

- Better service visibility
- Easier maintenance
- Improved governance
