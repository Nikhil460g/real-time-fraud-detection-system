# Domain Glossary

## Fraud Detection

The process of identifying suspicious or fraudulent transactions and activities.

## Transaction

A transfer of money or financial activity between two parties.

## Microservice

A small independent service that performs a specific task and communicates with other services through APIs.

## API

Application Programming Interface (API) is a set of rules that allows different software applications or services to communicate with each other.

## Rule Engine

A system that applies predefined rules to transactions and decides whether they are suspicious or safe.

## Real-Time Processing

The ability of a system to process and analyze data immediately as it is received.

## Anomaly Detection

The process of identifying unusual patterns or activities that do not match normal behavior.

## Fraud Score

A numerical value that indicates the likelihood of a transaction being fraudulent.

## Risk Assessment

The process of evaluating a transaction or activity to determine its level of risk.

## Graph Analysis

A technique used to analyze relationships and connections between users, accounts, devices, or transactions.

## Customer

A person or organization that uses banking or financial services and performs transactions.

## Account

A financial record maintained by a bank that stores customer funds and transaction history.

## Transaction Monitoring

The process of continuously observing transactions to identify suspicious activities.

## Alert

A notification generated by the system when suspicious activity is detected.

## Device

A computer, mobile phone, or other hardware used by a customer to access banking services.

## Blacklist

A list of accounts, users, or devices that are considered suspicious or fraudulent.

## Whitelist

A list of trusted accounts, users, or devices that are considered safe.

## Transaction History

A record of all past transactions performed by a customer or account.

## Authentication

The process of verifying the identity of a user before granting access to a system.

## Authorization

The process of determining what actions a user is allowed to perform after authentication.

## Dashboard

A visual interface that displays system information, alerts, reports, and performance metrics.

## Database

A structured collection of data used to store and manage information efficiently.

## User

A person who interacts with a software system to perform specific tasks.

## Service

An independent software component that performs a specific business function.

## Event

An action or occurrence within a system that can trigger further processing.

## Event Stream

A continuous flow of events generated by a system and processed in real time.

## Message Broker

A software system that enables communication between different services by transferring messages.

## Kafka

A distributed event streaming platform used to process and transfer large volumes of real-time data.

## Notification

A message sent to users or administrators to inform them about important events or alerts.

## Suspicious Activity

Any behavior or transaction that appears unusual and may indicate fraud.

## Fraud Alert

A warning generated by the system when a transaction is identified as potentially fraudulent.

## Machine Learning

A technology that enables systems to learn patterns from data and make predictions without explicit programming.

## Model

A trained machine learning component used to make predictions or decisions.

## Feature

A measurable attribute or characteristic used by a machine learning model for analysis.

## Prediction

The output generated by a model based on input data.

## False Positive

A legitimate transaction incorrectly identified as fraudulent.

## False Negative

A fraudulent transaction incorrectly identified as legitimate.

## Customer Profile

A collection of information that describes a customer's behavior, preferences, and transaction patterns.

## Transaction Limit

The maximum amount allowed for a transaction within a specified period.

## Risk Score

A numerical value representing the level of risk associated with a transaction.

## Audit Log

A record of system activities and events maintained for monitoring and investigation purposes.

## Account Holder

The person or organization that owns a bank account.

## Beneficiary

The person or organization receiving money in a transaction.

## Device Fingerprint

A unique set of characteristics used to identify a device accessing a system.

## Geolocation

The physical location of a user or device determined through technology.

## Transaction Pattern

A repeated behavior or trend observed in transaction data.

## Velocity Check

A fraud detection technique that monitors how frequently transactions occur within a given time period.

## Case Management

The process of investigating, tracking, and resolving fraud-related incidents.

## Compliance

The act of following regulatory, legal, and organizational requirements.

## Financial Institution

An organization such as a bank, insurance company, or credit union that provides financial services.
