# Architecture Decision Records

## ADR-001: Microservices Architecture

Decision:
Use microservices instead of a monolithic architecture.

Reason:
Improved scalability and independent deployment.

## ADR-002: Apache Kafka

Decision:
Use Kafka for event streaming.

Reason:
High throughput and reliability.

## ADR-003: Kubernetes

Decision:
Deploy services on Kubernetes.

Reason:
Container orchestration and scalability.

## ADR-004: PostgreSQL

Decision:
Use PostgreSQL as the primary transactional database.

Reason:
ACID compliance and reliability.
